# Traspaso Sistema

A full-stack web application built with:

* **Frontend:** React + Vite
* **Backend:** Node.js + Express
* **Database:** MySQL
* **ORM:**: Sequelize

## Installation

### Frontend

Navigate to the frontend directory and install the dependencies:

npm install

Start the development server:

npm run dev

### Backend

Navigate to the backend directory and install the dependencies:

npm install

Start the development server:

npm run dev

## Development

Make sure both the frontend and backend development servers are running simultaneously during development.
